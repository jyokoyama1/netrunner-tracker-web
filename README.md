# Netrunner Tracker

A token tracker for Android: Netrunner — clicks, credits, agenda points, bad publicity, tags, brain damage,

**Open:** https://jyokoyama1.github.io/netrunner-tracker-web/ — on iPhone, Safari → Share → Add to Home Screen.

Plain HTML/CSS/JS, works offline. See NOTES.md for details.
